Description
The diagram details the sequence of events from the launch of the mobile application to the presentation of the user interface on the Dashboard, including the connection between the application and the CoolManager, as well as the established connection between the CoolManager and the Refrigerator.

Diagram Flow
Launch Application:

The user initiates the mobile application.
Initiate Connection:

The mobile application starts the connection with the CoolManager.
Establish Connection:

The CoolManager establishes the connection with the Refrigerator.
Notify Connection Established:

The Refrigerator notifies the CoolManager about the established connection.
Show Dashboard:

Upon receiving the notification of the established connection, the CoolManager informs the mobile application, which activates the Dashboard to display the user interface to the user.
